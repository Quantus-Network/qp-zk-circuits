# qp-wormhole-verifier

Verifier logic for the Wormhole circuit.

This crate provides the `WormholeVerifier` type, which allows for the verification of
zero-knowledge proofs generated by the Wormhole circuit.

The typical usage flow involves:

1. Load canonical artifacts with `WormholeVerifier::new_from_bytes`.
2. Decode and verify network proof bytes with `WormholeVerifier::verify_bytes`.

Existing consumers must replace direct `ProofWithPublicInputs::from_bytes`
calls with `verify_bytes`, or with `decode_proof` followed by verification.
The re-exported upstream type retains its original unbounded decoder.

## Example

Create a verifier and verify a proof:

```rust
use qp_wormhole_verifier::WormholeVerifier;

fn verify(verifier_bytes: &[u8], common_bytes: &[u8], proof_bytes: &[u8]) -> anyhow::Result<()> {
    let verifier = WormholeVerifier::new_from_bytes(verifier_bytes, common_bytes)?;
    let _verified_proof = verifier.verify_bytes(proof_bytes)?;
    Ok(())
}
```
